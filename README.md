# 🕉️ Mahakumbh Assistant: Divine AI Pilgrim Guide

![Mahakumbh Assistant Avatar](./public/avatar.png)

## Overview
The **Mahakumbh Assistant** is an AI-powered, voice-activated "Divine Avatar" designed to guide and assist pilgrims during the Mahakumbh Mela 2025. It provides a seamless, highly interactive interface that supports 20 different languages, ensuring that any pilgrim can access vital information, directions, and spiritual guidance in their native tongue.

By leveraging cutting-edge AI and Speech APIs, this project aims to create an inclusive, accessible, and magical experience for millions of devotees.

---

## Key Features
- ** Multilingual Voice Assistant**: Features an advanced voice-activated assistant supporting 20 languages, utilizing the Web Speech API for real-time speech recognition and synthesis.
- ** AI Chatbot**: Powered by Google's Gemini AI to provide highly accurate, contextual, and culturally aware responses to pilgrims' queries.
- ** 20-Language Support**: Completely localized interface and interactions, breaking down language barriers for devotees from all over the world.
- ** Fast & Responsive**: Built with React and Vite for blazing fast performance across all devices (mobile-first approach).
- ** Divine Aesthetics**: A visually stunning UI featuring glassmorphism and modern design principles to reflect the grandeur of the Mahakumbh.

---

## Technology Stack
- **Frontend Framework**: React.js
- **Build Tool**: Vite
- **AI Integration**: Google Gemini API (`@google/generative-ai`)
- **Voice Capabilities**: Web Speech API (Speech Recognition & Speech Synthesis)
- **Styling**: Vanilla CSS / Glassmorphism UI

## Getting Started

To run this project locally on your machine, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/Cy-nape/Mahakumbh-Guide.git
cd Mahakumbh-Guide
```

### 2. Install Dependencies
Make sure you have Node.js installed, then run:
```bash
npm install
```

### 3. Environment Setup
Create a `.env` file in the root of your project and add your Google Gemini API key:
```env
VITE_GEMINI_API_KEY=your_api_key_here
```

### 4. Run the Development Server
```bash
npm run dev
```
The application will be running at `http://localhost:5173/`.
